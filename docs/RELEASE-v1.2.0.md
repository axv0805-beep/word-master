# 词芽 v1.2.0

## 新功能

- 新增 AI 写作批改、单词联想、例句生成与语境出题。
- 支持 DeepSeek、OpenAI、通义千问、Kimi、智谱、硅基流动、Claude、Gemini 等厂商预设，自定义接口地址、协议与模型 ID，支持获取模型列表和测试连接。
- 新增管理员接口管理、学习账号、每日额度、按账号隔离的生成历史；厂商密钥在后台加密保存。
- 写作草稿自动保存，提供计时与字数统计；学习级别、模型与厂商选择面板适配手机及深色主题。

## 合并作者更新

- 合并截至 1.1.20（030e49a）的听力题库、随机抽题、听力错题、TTS 音色和 GitHub Release 更新改进。
- 保留 40 道离线写作题、本地批改和范文，与 AI 写作独立使用；双方存档及备份字段兼容。

## 使用说明

AI 后台目前为本地运行版本，需 Node.js 24+。运行 `npm run local`，在设置中创建管理员、配置模型接口并开放模型。公共 AI 后台尚未部署；GitHub Pages 和 APK 不会自动启动后台，也不附带任何厂商密钥或额度。

Android 的 AI 联网功能需要在打包时通过 `VITE_AI_API_BASE_URL` 指定已部署的 HTTPS 后台，并配置对应来源；配置前可使用原有离线功能。详见仓库 `docs/AI本地开发.md`。
