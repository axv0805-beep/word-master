### 错题再次出现频率：四档策略的具体行为

由 `replayGap()` 与 `RoundEngine.scheduleReplay()` 实现，同一单词在一轮内最多重现一次（避免队列无限增长）：

| 策略 | 行为 | 插入位置 |
|---|---|---|
| 立即重出 | 答错后隔 1 题再问一次 | `cursor + 1 + 1` |
| 每 N 题重现 | N 可调 3–50，默认 10 | `cursor + 1 + N` |
| 轮末集中复习 | 本轮错词在最后成组重考 | 队列末尾 |
| 智能间隔（艾宾浩斯简版 SM-2） | 答对：1 天 → 3 天 → 上次间隔 × 难度因子；答错：间隔归零（10 分钟后重现），难度因子下调（下限 1.3）。轮内错题隔 5 题重现 | `cursor + 1 + 5` |

另有「连对几次移出错题本」（1–5 次，默认 2）：错题被连续答对达到阈值后自动移出，同时该词标记为「已掌握」。

## 新增：首次进入的学习计划引导

| 需求点 | 实现 | 文件位置 |
|---|---|---|
| 进入后先让用户选择背哪本书 | 首次打开（存档里没有 `onboarded` 且无任何学习数据）直接显示引导第 1 步，列出内置 4 本 + 自定义词书，带词数与已学进度条 | `src/pages/Onboarding.tsx`、`src/App.tsx` |
| 自己选择每天的目标 | 第 2 步：10/20/30/50/100 快捷档位 + ± 步进（5–300），自定义时实时给出预估 | `src/pages/Onboarding.tsx`、`src/core/constants.ts` |
| 每轮单词数随目标变化 | 同一屏下方给出「每轮单词数」，**可选档位由每日目标推导**（最低 10、最高 = 目标），目标一变档位立刻跟着变 | `src/pages/Onboarding.tsx`、`src/core/constants.ts` |
| 选完自动生成「多少天背完整本书」 | 第 3 步：`buildStudyPlan()` 计算预计天数、折算月/周、预计完成日期、每天约需几轮；首页与设置页复用同一口径 | `src/core/plan.ts`、`src/pages/Home.tsx`、`src/pages/Settings.tsx` |
| 不打扰老用户 | 存档中已有 progress/daily/rounds 且没有 `onboarded` 字段时，推断为已完成引导 | `src/store/appStore.ts` |
| 随时重走引导 | 设置页「学习计划」卡片 →「重新选择词书与每日目标」 | `src/pages/Settings.tsx` |
| 天数口径 | `剩余 = 总词数 − 已学`；`天数 = ceil(剩余 ÷ 每日目标)`；第 1 天算今天（`days=1` → 今天完成） | `src/core/plan.ts` |
