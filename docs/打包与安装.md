# 打包与安装

本文说明如何把「单词王」变成两种可直接使用的形态：

1. **Windows 桌面程序**（免安装 exe，电脑上查看/使用）
2. **手机 PWA**（部署到 GitHub Pages 后「添加到主屏幕」，全屏、离线）

> 先说结论：本项目是 Web 应用，**不能双击 `dist/index.html` 打开**。`file://` 下浏览器会拦截 ES module 脚本和样式，Service Worker 也无法注册，结果就是白屏。所有方式都必须通过 http/https 访问。

---

## 一、Windows 桌面版

### 1. 打包

```bash
npm install          # 首次
npm run package:desktop
```

脚本会依次做：

1. `npm run build` 生成 `dist/`
2. 首次运行时下载 Electron 33 运行时（约 110 MB）到 `.electron/`
3. 组装到 `release/单词王-win32-x64/`，写入程序图标和版本信息
4. 额外打一个 `release/单词王-桌面版.zip`

产物：

```
release/
├── 单词王-win32-x64/
│   ├── 单词王.exe        ← 双击这个
│   ├── resources/app/    ← 页面代码 + dist
│   └── *.dll, *.pak ...  ← Electron 运行库
└── 单词王-桌面版.zip      ← 整个目录的压缩包
```

> **分发时请发整个文件夹（或 zip）**，不要只发 `单词王.exe`：它依赖同目录下的 dll 和 `resources/`。

### 2. 开发调试

```bash
npm run electron:dev
```

直接开窗口，改前端代码后 `npm run build` 重新构建、再启动即可。窗口里按 **F12** 打开开发者工具。

### 3. 桌面版的行为

- 窗口默认 430×900（手机比例），可自由缩放/最大化，画面始终按 480px 宽居中
- 启动时在 `127.0.0.1` 的随机端口起一个只读静态服务，窗口加载它，因此绕开了 `file://` 的限制
- 外部链接用系统浏览器打开
- 单实例：重复双击只会聚焦已打开的窗口
- 学习数据存在 Electron 的用户数据目录（`%APPDATA%\<应用名>` 下），卸载时删除该目录即可清空

### 4. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 双击后 SmartScreen 提示「未知发布者」 | 没有做代码签名，点「更多信息 → 仍要运行」即可 |
| 打包时下载 Electron 失败 | 手动下载 `https://npmmirror.com/mirrors/electron/33.2.0/electron-v33.2.0-win32-x64.zip` 放进 `.electron/` 后再跑一次 |
| 想换图标 | 替换 `build/icon.ico` 后重新 `npm run package:desktop` |
| 想清空重来 | 删掉 `release/` 和 `.electron/`，再打包 |

## 二、手机 PWA（装到主屏幕）

### 为什么不能直接用局域网 IP 安装

Service Worker / 可安装 PWA 要求**安全上下文**：`https://` 或 `localhost`。手机访问 `http://192.168.x.x:5173` 只是普通网页，能预览，但「添加到主屏幕」不会变成独立 App、也不能离线。

所以正式安装走 GitHub Pages（自带 HTTPS）。

### 1. 部署到 GitHub Pages

仓库里已经放好工作流 `.github/workflows/deploy-pages.yml`，推送 `main` 分支就会自动构建并发布。

首次需要手动开启一次：

1. 打开仓库 → **Settings → Pages**
2. **Build and deployment → Source** 选 **GitHub Actions**
3. 到 **Actions** 标签页，等「部署 PWA 到 GitHub Pages」跑完
4. 页面会给出地址，形如 `https://<用户名>.github.io/word-master/`

之后每次 `git push` 都会自动更新。

### 2. 手机上安装

**Android（Chrome / Edge）**

1. 用手机浏览器打开上面的 Pages 地址
2. 地址栏右侧出现「安装」图标，或菜单 →「安装应用 / 添加到主屏幕」
3. 桌面会出现「单词王」图标，点开是全屏、无地址栏

**iPhone（Safari）**

1. Safari 打开 Pages 地址
2. 点底部「分享」→「添加到主屏幕」→ 添加

> iOS 上需要先随便用一次（加载词书）再断网，离线才完整；PWA 的缓存策略已在 `vite.config.ts` 里配置（词书 JSON 走 CacheFirst，缓存一年）。

### 3. 局域网临时预览（不安装）

```bash
npm run dev -- --host
# 或 npm run preview -- --host
```

手机浏览器访问 `http://<电脑IP>:5173`。仅用于看效果，不具备 PWA 的离线/全屏能力。

## 三、实现说明

| 文件 | 作用 |
|---|---|
| `electron/main.cjs` | Electron 主进程：本地静态服务 + 窗口 + 外部链接 + F12 |
| `scripts/electron-runtime.mjs` | 下载/解压 Electron 运行时、下载 rcedit |
| `scripts/electron-dev.mjs` | `npm run electron:dev` |
| `scripts/package-desktop.mjs` | `npm run package:desktop`：组装 + 图标 + zip |
| `build/icon.ico` | 程序图标（由 `public/icons/icon-512.png` 生成） |
| `.github/workflows/deploy-pages.yml` | GitHub Pages 自动部署 |

打包不会修改 `src/` 和 `vite.config.ts`，前端代码与桌面壳、PWA 完全共用一份 `dist/`。
